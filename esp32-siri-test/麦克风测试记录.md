# Siri Remote 麦克风经 ESP32 接收实测

时间：2026-09-14 23:09–23:11，Asia/Singapore。

## 结论与范围

第三代 Siri Remote 的麦克风音频可由 Waveshare ESP32-S3-Touch-LCD-3.5 经 BLE 接收，再通过 USB 串口传到本机解码为 WAV。第二次用户实际说话测试取得 5.74 秒、48kHz、16bit、单声道音频；287 个有效 Opus 帧全部解码成功，无序号缺口、无固件队列丢帧。

本次没有使用板载麦克风、Mac 麦克风或网络音频。ESP32 负责 BLE 接收和 USB 串口传输，Opus 解码在 Mac 本机完成；尚未实现 ESP32 内部解码和标准 USB Audio Class 麦克风，不能据此声称微信输入法已能直接选用这个设备。没有进行语音识别或人工听感验收；录音可由用户回放。单次短录音不代表长期稳定性已经验收。

## 两次录音对比

| 指标 | 第一次，build 3 | 第二次，build 4 |
|---|---:|---:|
| 解码成功帧 | 145 | 287 |
| 解码错误 | 0 | 0 |
| 序号缺包 | 114 | 0 |
| 固件队列丢帧 | 0 | 0 |
| WAV 时长 | 2.90 秒 | 5.74 秒 |
| RMS | -22.41 dBFS | -19.39 dBFS |

第一次证明可以收到真实音频，但存在缺包，保存的声音时长短于实际说话时长。build 4 将 BLE 连接请求间隔改为 12 单位（15ms）、延迟 0、超时 2 秒，匹配约 20ms 一帧的 Opus 数据流；第二次序号连续。该对照支持这项修改有效，但未保存第一次的实际协商间隔，不应将请求值当作已测得的协商值。

第二次收到 288 个 FA 数据包，其中 287 个音频帧和 1 个结束标记；20 个样本达到满幅（共 275,520 个样本），保留原始解码音量，未做增益或降噪处理。
