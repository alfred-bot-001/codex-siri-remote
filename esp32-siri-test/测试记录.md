# ESP32-S3 与 Siri Remote 连接实测

时间：2026-09-14 23:02–23:06，Asia/Singapore。

## 结论

Waveshare ESP32-S3-Touch-LCD-3.5 能与用户的第三代 Apple TV Siri Remote 配对、建立加密连接，并接收真实按键按下及松开通知。已验证 ESP32 更新固件重启后保留绑定，普通按键唤醒遥控器即可重连，无需重新进入配对模式。

这是 BLE 连接与按键验证，不是完整 USB 键盘/麦克风验收。没有向 Mac 发送键盘输入，没有订阅或录制麦克风音频。未验证长期待机和多次断电稳定性，未测量整机功耗。

## 硬件与固件

- ESP32-S3 rev 0.2，芯片 MAC 10:20:BA:46:58:B4，内置 8MB PSRAM，16MB Flash。
- 串口 `/dev/cu.usbmodem21301`；原生 USB-Serial/JTAG。
- 遥控器身份 28:2D:7F:3F:50:6E，初次扫描 RSSI -32 dBm。
- PlatformIO espressif32 6.12.0、Arduino 框架、NimBLE-Arduino 2.3.6。
- 当前诊断固件 build 2，SHA-256 `f9821cdbbdbb08f3e07ba23540838e14d485c2fc441f80fbf61a581de908c804`。
- 编译通过；两次刷写均通过 esptool 写入哈希校验。

## 证据

初次：23:02:47 `LINK_CONNECTED`；23:02:48 `AUTH encrypted=1 bonded=1 authenticated=0`。使用 Just Works 加密绑定，不具备 MITM 认证；不能将 authenticated=0 误判成未加密。

枚举到 HID 输入报告 FA、FB、FC、60、FD、FE 和特征报告 F0、F1。只订阅 FB 按键；F0 写入 0xAF 成功，F1 拒绝。F0 成功后已获得实际按键，无需宣称 F1 写入成功。

23:02:50 收到返回键 0x0040 与释放 0x0000；23:02:54 收到返回键加音量加 0x0042。23:02:55 对端主动断开，NimBLE reason=531（HCI 0x13）。该时段不能算稳定连接；用户随后第一次方向键测试没有被接收。

更新同一目标重连逻辑后，23:05:18 恢复加密绑定，23:05:20 接收到确认键按下 0x0008 与释放 0x0000。
